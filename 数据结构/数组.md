# 数组

## 什么是数组

数组是一段**连续内存**中存放的**同类型元素**集合，通过下标实现 **O(1) 随机访问**。

| | 数组 | 链表 |
| --- | --- | --- |
| 随机访问 | O(1) | O(n) |
| 插入 / 删除 | O(n)（要搬移元素） | O(1)（已知位置） |
| 内存 | 连续 | 分散 |

## Python 里的数组（list）

```python
a = [1, 2, 3]
a[0]            # 访问，O(1)
a[-1]           # 最后一个元素
len(a)          # 长度
a.append(4)     # 末尾追加，O(1) 均摊
a.insert(0, 0)  # 头部插入，O(n)
a.pop()         # 末尾删除，O(1)
a[1:3]          # 切片
a.sort()        # 排序，O(n log n)
a.reverse()     # 反转，O(n)
```

## 数组的常见技巧

1. **遍历**：`for i in range(len(a))` / `for x in a` / `for i, x in enumerate(a)`
2. **原地修改**：双指针（见「双指针」专题）
3. **区间求和**：前缀和（见「前缀和」专题）
4. **原地反转**：切片 `a[::-1]` 或双指针，用于轮转数组等
5. **排序 + 双指针**：先排序再处理

## 模板

### 模板一：原地反转（双指针）

```python
def reverse(a, left, right):
    while left < right:
        a[left], a[right] = a[right], a[left]
        left += 1
        right -= 1
```

### 模板二：三次反转实现轮转

```python
k %= len(nums)
reverse(nums, 0, n - 1)      # 整体反转
reverse(nums, 0, k - 1)      # 前 k 个反转
reverse(nums, k, n - 1)      # 后 n-k 个反转
```

## 例题（hot100）

### 例题 1：轮转数组（LeetCode 189）

**题目**：把数组 `nums` 向右轮转 k 步（原地）。例：`[1,2,3,4,5,6,7]`, k=3 → `[5,6,7,1,2,3,4]`

#### 思路：三次反转

```plain
原数组:      [1, 2, 3, 4, 5, 6, 7]
整体反转:    [7, 6, 5, 4, 3, 2, 1]
前 k 个反转: [5, 6, 7, 4, 3, 2, 1]
后 n-k 反转: [5, 6, 7, 1, 2, 3, 4]  ← 答案
```

```python
def rotate(nums, k):
    n = len(nums)
    k %= n
    def rev(l, r):
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
    rev(0, n - 1)
    rev(0, k - 1)
    rev(k, n - 1)
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(1)（原地） |

### 例题 2：除自身以外数组的乘积（LeetCode 238）

**题目**：返回数组 `ans`，其中 `ans[i]` 等于 `nums` 中**除 `nums[i]` 外**其余元素的乘积（不能用除法）。

#### 思路

`ans[i]` = 左边所有数的乘积 × 右边所有数的乘积。先从左往右算「前缀积」，再从右往左乘「后缀积」。

```python
def productExceptSelf(nums):
    n = len(nums)
    ans = [1] * n
    # 第一遍：ans[i] 存左边的乘积
    for i in range(1, n):
        ans[i] = ans[i - 1] * nums[i - 1]
    # 第二遍：从右往左乘上右边的乘积
    right = 1
    for i in range(n - 1, -1, -1):
        ans[i] *= right
        right *= nums[i]
    return ans
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(1)（不算返回数组） |

### 例题 3：合并区间（LeetCode 56）

**题目**：合并所有重叠区间。例：`[[1,3],[2,6],[8,10],[15,18]]` → `[[1,6],[8,10],[15,18]]`

#### 思路

先按区间起点排序，再逐个判断：新区间和结果最后一个区间重叠就扩展右边界，否则加入结果。

```python
def merge(intervals):
    intervals.sort()                 # 按起点排序
    res = []
    for it in intervals:
        if not res or res[-1][1] < it[0]:   # 不重叠
            res.append(it)
        else:                               # 重叠，扩展右边界
            res[-1][1] = max(res[-1][1], it[1])
    return res
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n log n)（排序） |
| 空间 | O(n)（结果） |

### 例题 4：缺失的第一个正数（LeetCode 41，进阶）

**题目**：找出未排序数组中缺失的最小正整数，要求 **O(n) 时间、O(1) 空间**。

#### 思路：原地哈希

把数字 `x`（`1 ≤ x ≤ n`）放到下标 `x-1` 的位置；最后第一个「下标和值对不上」的位置就是答案。

```python
def firstMissingPositive(nums):
    n = len(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n)（每个数最多交换一次） |
| 空间 | O(1) |

## 识别信号

- ✅ 需要 **O(1) 随机访问** → 数组
- ✅ 频繁**末尾**操作 → 数组（append / pop）
- ✅ **原地**修改、**原地**反转 → 数组 + 双指针
- ✅ **区间求和 / 乘积** → 前缀和 / 前缀积

## 常见易错点

1. **下标越界**：循环条件用 `i < n` 而不是 `i <= n`。
2. **原地修改覆盖**：交换前先存被覆盖的值。
3. **k 取模**：轮转数组的 `k` 可能大于 `n`，先 `k %= n`。
4. **空数组**：`if not nums: return ...`。
5. **负数 / 0 处理**：缺失的第一个正数要跳过非正数（`1 <= nums[i] <= n` 条件）。

## 一句话总结

**数组 = 连续内存 + O(1) 随机访问；核心技巧是「原地 + 双指针 + 前缀和 + 排序」。**
