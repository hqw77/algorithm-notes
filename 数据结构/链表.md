# 链表

## 什么是链表

链表由**节点**组成,每个节点存"数据"和"指向下一个节点的指针",内存**不连续**.

| | 数组 | 链表 |
| --- | --- | --- |
| 随机访问 | O(1) | O(n) |
| 插入 / 删除 | O(n) | O(1)(已知位置) |
| 内存 | 连续 | 分散 |

## Python 链表节点定义

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

## 链表核心技巧

1. **哑节点(dummy)**:新建一个虚拟头节点,统一处理头节点的删除 / 插入.
2. **快慢指针**:`slow` 走一步,`fast` 走两步,用于找中点,判断环.
3. **反转指针**:逐个把 `cur.next` 指向前一个节点.
4. **递归**:链表天然适合递归(反转,合并).

## 模板

### 模板一:反转链表(迭代)

```python
def reverseList(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next    # 先存下一个
        cur.next = prev   # 反转指针
        prev = cur
        cur = nxt
    return prev
```

### 模板二:快慢指针(判环 / 找中点)

```python
slow = fast = head
while fast and fast.next:
    slow = slow.next        # 走一步
    fast = fast.next.next   # 走两步
    # 判环:if slow == fast: return True
# 找中点:循环结束 slow 指向中点(偶数个时偏右)
```

### 模板三:哑节点 + 双指针(删除倒数第 N 个)

```python
dummy = ListNode(0, head)
fast = slow = dummy
for _ in range(n + 1):      # fast 先走 n+1 步
    fast = fast.next
while fast:
    fast = fast.next
    slow = slow.next
slow.next = slow.next.next  # 删除 slow.next
return dummy.next
```

## 例题(hot100)

### 例题 1:反转链表(LeetCode 206)

**题目**:反转一个单链表.

```python
def reverseList(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev
```

#### 图解

```plain
原始: 1 -> 2 -> 3 -> None
过程: prev=null, cur=1
      先存 nxt=2,再让 1 指向 null
      逐步: 2 -> 1 -> null, 3 -> 2 -> 1 -> null
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(1) |

### 例题 2:环形链表(LeetCode 141)

**题目**:判断链表是否有环.

```python
def hasCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

#### 图解

快指针每次比慢指针多走一步,有环则快指针最终会追上慢指针.

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(1) |

---

### 例题 3:合并两个有序链表(LeetCode 21)

**题目**:合并两个升序链表为一个升序链表.

```python
def mergeTwoLists(l1, l2):
    dummy = ListNode(0)
    cur = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next
    cur.next = l1 if l1 else l2    # 接上剩余部分
    return dummy.next
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(m + n) |
| 空间 | O(1) |

---

### 例题 4:删除链表的倒数第 N 个结点(LeetCode 19)

**题目**:删除链表倒数第 n 个节点,返回头节点.

```python
def removeNthFromEnd(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n + 1):        # fast 先走 n+1 步
        fast = fast.next
    while fast:
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next    # 删除 slow.next
    return dummy.next
```

#### 图解

`fast` 先领先 `slow` n+1 步,一起走;`fast` 到末尾时,`slow` 正好在要删节点的**前一个**.

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(1) |

## 识别信号

- ✅ 单向,节点带 `next` -> 链表
- ✅ 找**中点**,判断**环** -> 快慢指针
- ✅ 删除 / 插入**头节点** -> 哑节点
- ✅ **反转**,**合并** -> 迭代 / 递归

## 常见易错点

1. **空链表 / 单节点**:先 `if not head or not head.next: return ...`.
2. **空指针**:访问 `cur.next.next` 前先判断 `cur.next` 是否为 None.
3. **删除头节点**:用哑节点统一处理,别单独特判.
4. **快指针越界**:循环条件是 `while fast and fast.next`,不是 `while fast.next`.
5. **返回错节点**:删除 / 插入后返回 `dummy.next`,因为头节点可能已变.

## 一句话总结

**链表 = 指针串起来的节点;核心是"哑节点统一边界 + 快慢指针 + 反转指针".**
