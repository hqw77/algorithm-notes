# 螺旋矩阵
## <font style="color:rgb(15, 17, 21);">什么是螺旋矩阵</font>
<font style="color:rgb(15, 17, 21);">螺旋矩阵（Spiral Matrix）指的是：</font>

<font style="color:rgb(15, 17, 21);">按照</font>**<font style="color:rgb(15, 17, 21);">顺时针（或逆时针）螺旋顺序</font>**<font style="color:rgb(15, 17, 21);">遍历一个二维矩阵，从外圈向内圈一层层走。</font>

<font style="color:rgb(15, 17, 21);">比如矩阵：</font>

<font style="color:rgb(15, 17, 21);"></font>

```plain
1  2  3
4  5  6
7  8  9
```



<font style="color:rgb(15, 17, 21);">顺时针螺旋遍历顺序是：</font>

```plain
1 → 2 → 3 → 6 → 9 → 8 → 7 → 4 → 5
```

<font style="color:rgb(15, 17, 21);">即：</font>**<font style="color:rgb(15, 17, 21);">右 → 下 → 左 → 上 → 右 → 下 → ...</font>**<font style="color:rgb(15, 17, 21);">，一圈一圈往里缩。</font>

## <font style="color:rgb(15, 17, 21);">两种常见题型</font>
| <font style="color:rgb(15, 17, 21);">题型</font> | <font style="color:rgb(15, 17, 21);">描述</font> |
| --- | --- |
| **<font style="color:rgb(15, 17, 21);">遍历型</font>** | <font style="color:rgb(15, 17, 21);">按螺旋顺序</font>**<font style="color:rgb(15, 17, 21);">输出</font>**<font style="color:rgb(15, 17, 21);">矩阵所有元素</font> |
| **<font style="color:rgb(15, 17, 21);">生成型</font>** | <font style="color:rgb(15, 17, 21);">按螺旋顺序</font>**<font style="color:rgb(15, 17, 21);">填充</font>**<font style="color:rgb(15, 17, 21);">一个 n×n 矩阵</font> |


<font style="color:rgb(15, 17, 21);">两者思路一致，方向相反。</font>

## <font style="color:rgb(15, 17, 21);">核心思路：边界收缩</font>
<font style="color:rgb(15, 17, 21);">维护四个边界：</font>

```plain
top    上边界
bottom 下边界
left   左边界
right  右边界
```

<font style="color:rgb(15, 17, 21);">每一轮走四条边：</font>

```plain
① 从左到右：top 行，left → right
② 从上到下：right 列，top+1 → bottom
③ 从右到左：bottom 行，right-1 → left
④ 从下到上：left 列，bottom-1 → top+1
```

<font style="color:rgb(15, 17, 21);">走完一轮，四个边界</font>**<font style="color:rgb(15, 17, 21);">同时向内收缩</font>**<font style="color:rgb(15, 17, 21);">：</font>

```plain
top++
bottom--
left++
right--
```

<font style="color:rgb(15, 17, 21);">直到 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top > bottom</font>`<font style="color:rgb(15, 17, 21);"> 或 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left > right</font>`<font style="color:rgb(15, 17, 21);">，结束。</font>

## <font style="color:rgb(15, 17, 21);">遍历型：螺旋矩阵</font>
<font style="color:rgb(15, 17, 21);">给一个 m×n 矩阵，按顺时针螺旋顺序返回所有元素。</font>

```plain
def spiralOrder(matrix):
    if not matrix or not matrix[0]:
        return []
    
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    res = []
    
    while top <= bottom and left <= right:
        # ① 从左到右：top 行
        for j in range(left, right + 1):
            res.append(matrix[top][j])
        top += 1
        
        # ② 从上到下：right 列
        for i in range(top, bottom + 1):
            res.append(matrix[i][right])
        right -= 1
        
        # ③ 从右到左：bottom 行（要判断 top <= bottom）
        if top <= bottom:
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1
        
        # ④ 从下到上：left 列（要判断 left <= right）
        if left <= right:
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1
    
    return res
```

### <font style="color:rgb(15, 17, 21);">第 1 轮</font>
**<font style="color:rgb(15, 17, 21);">① 从左到右（top 行 = 第 0 行）</font>**

```plain
1 → 2 → 3 → 4       res = [1,2,3,4]
top 变成 1
```

**<font style="color:rgb(15, 17, 21);">② 从上到下（right 列 = 第 3 列，从第 1 行开始）</font>**

```plain
8 → 12              res = [1,2,3,4,8,12]
right 变成 2
```

**<font style="color:rgb(15, 17, 21);">③ 从右到左（bottom 行 = 第 2 行，从第 2 列到第 0 列）</font>**

```plain
11 → 10 → 9         res = [...,11,10,9]
bottom 变成 1
```

**<font style="color:rgb(15, 17, 21);">④ 从下到上（left 列 = 第 0 列，从第 1 行到第 1 行）</font>**

```plain
5                   res = [...,5]
left 变成 1
```

<font style="color:rgb(15, 17, 21);">此时：</font>

```plain
top=1, bottom=1, left=1, right=2
```

### <font style="color:rgb(15, 17, 21);">第 2 轮</font>
**<font style="color:rgb(15, 17, 21);">① 从左到右（top 行 = 第 1 行，第 1 列到第 2 列）</font>**

```plain
6 → 7               res = [...,6,7]
top 变成 2
```

**<font style="color:rgb(15, 17, 21);">② 从上到下（right 列 = 第 2 列，从第 2 行到第 1 行）</font>**<font style="color:rgb(15, 17, 21);"> → 空（top=2 > bottom=1）</font>

**<font style="color:rgb(15, 17, 21);">③ ④</font>**<font style="color:rgb(15, 17, 21);"> 同理不执行。</font>

<font style="color:rgb(15, 17, 21);">此时 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top=2 > bottom=1</font>`<font style="color:rgb(15, 17, 21);">，结束。</font>

**<font style="color:rgb(15, 17, 21);">最终结果：</font>**

```plain
[1, 2, 3, 4, 8, 12, 11, 10, 9, 5, 6, 7]
```

### <font style="color:rgb(15, 17, 21);">关键点：两个 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">if</font>`<font style="color:rgb(15, 17, 21);"> 判断</font>
<font style="color:rgb(15, 17, 21);">这是</font>**<font style="color:rgb(15, 17, 21);">最容易出错</font>**<font style="color:rgb(15, 17, 21);">的地方：</font>

```plain
if top <= bottom:      # ③ 从右到左前判断
if left <= right:      # ④ 从下到上前判断
```

**<font style="color:rgb(15, 17, 21);">为什么需要？</font>**

<font style="color:rgb(15, 17, 21);">因为当矩阵</font>**<font style="color:rgb(15, 17, 21);">只剩一行或一列</font>**<font style="color:rgb(15, 17, 21);">时，③④ 会</font>**<font style="color:rgb(15, 17, 21);">重复遍历</font>**<font style="color:rgb(15, 17, 21);">。</font>

### <font style="color:rgb(15, 17, 21);">例子：只有一行</font>
```plain
matrix = [[1, 2, 3]]
top=0, bottom=0, left=0, right=2
```

<font style="color:rgb(15, 17, 21);">走完 ① 后：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">res=[1,2,3]</font>`<font style="color:rgb(15, 17, 21);">，</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top=1</font>`<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(15, 17, 21);">此时 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top=1 > bottom=0</font>`<font style="color:rgb(15, 17, 21);">。</font>

+ <font style="color:rgb(15, 17, 21);">② 循环 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">range(1, 1)</font>`<font style="color:rgb(15, 17, 21);"> → 空，安全</font>
+ <font style="color:rgb(15, 17, 21);">③ 如果不判断，会执行 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">range(2, -1, -1)</font>`<font style="color:rgb(15, 17, 21);"> → 又输出 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">3,2,1</font>`<font style="color:rgb(15, 17, 21);">，</font>**<font style="color:rgb(15, 17, 21);">重复！</font>**
+ <font style="color:rgb(15, 17, 21);">④ 如果不判断，会执行 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">range(...)</font>`<font style="color:rgb(15, 17, 21);"> → 也可能重复</font>

<font style="color:rgb(15, 17, 21);">所以必须加：</font>

```plain
if top <= bottom:   # 1 <= 0 为假，跳过 ③
if left <= right:   # 0 <= 2 为真，但 ④ 的 range 可能为空
```

### <font style="color:rgb(15, 17, 21);">例子：只有一列</font>
```plain
matrix = [[1],
          [2],
          [3]]
top=0, bottom=2, left=0, right=0
```

<font style="color:rgb(15, 17, 21);">走完 ① 后：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">res=[1]</font>`<font style="color:rgb(15, 17, 21);">，</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top=1</font>`<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(15, 17, 21);">走完 ② 后：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">res=[1,2,3]</font>`<font style="color:rgb(15, 17, 21);">，</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right=-1</font>`<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(15, 17, 21);">此时 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left=0 > right=-1</font>`<font style="color:rgb(15, 17, 21);">。</font>

+ <font style="color:rgb(15, 17, 21);">③ 判断 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top <= bottom</font>`<font style="color:rgb(15, 17, 21);">：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">1 <= 2</font>`<font style="color:rgb(15, 17, 21);"> 为真，会执行 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">range(-1, -1, -1)</font>`<font style="color:rgb(15, 17, 21);"> → 空，安全</font>
+ <font style="color:rgb(15, 17, 21);">④ 判断 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left <= right</font>`<font style="color:rgb(15, 17, 21);">：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">0 <= -1</font>`<font style="color:rgb(15, 17, 21);"> 为假，跳过</font>

**<font style="color:rgb(15, 17, 21);">结论：两个 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">if</font>**`**<font style="color:rgb(15, 17, 21);"> 是为了防止在单行/单列时重复访问。</font>**<font style="color:rgb(15, 17, 21);">  
</font><font style="color:rgb(15, 17, 21);"> </font>

## <font style="color:rgb(15, 17, 21);">生成型：螺旋矩阵 II</font>
<font style="color:rgb(15, 17, 21);">给 n，生成一个 n×n 的螺旋矩阵，元素从 1 到 n²。</font>

<font style="color:rgb(15, 17, 21);">思路一样，只是</font>**<font style="color:rgb(15, 17, 21);">填数</font>**<font style="color:rgb(15, 17, 21);">而不是</font>**<font style="color:rgb(15, 17, 21);">读数</font>**<font style="color:rgb(15, 17, 21);">。</font>

```plain
def generateMatrix(n):
    matrix = [[0] * n for _ in range(n)]
    top, bottom = 0, n - 1
    left, right = 0, n - 1
    num = 1
    
    while top <= bottom and left <= right:
        # ① 左到右
        for j in range(left, right + 1):
            matrix[top][j] = num
            num += 1
        top += 1
        
        # ② 上到下
        for i in range(top, bottom + 1):
            matrix[i][right] = num
            num += 1
        right -= 1
        
        # ③ 右到左
        if top <= bottom:
            for j in range(right, left - 1, -1):
                matrix[bottom][j] = num
                num += 1
            bottom -= 1
        
        # ④ 下到上
        if left <= right:
            for i in range(bottom, top - 1, -1):
                matrix[i][left] = num
                num += 1
            left += 1
    
    return matrix
```

### <font style="color:rgb(15, 17, 21);">示例</font>
```plain
generateMatrix(3)
```

<font style="color:rgb(15, 17, 21);">结果：</font>

```plain
[[1, 2, 3],
 [8, 9, 4],
 [7, 6, 5]]
```

## <font style="color:rgb(15, 17, 21);">常见易错点</font>
### <font style="color:rgb(15, 17, 21);">1. 忘记两个 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">if</font>`<font style="color:rgb(15, 17, 21);"> 判断</font>
```plain
# ❌ 单行/单列时会重复
for j in range(right, left - 1, -1):
    res.append(matrix[bottom][j])
bottom -= 1
for i in range(bottom, top - 1, -1):
    res.append(matrix[i][left])
left += 1

# ✅ 加上判断
if top <= bottom:
    ...
if left <= right:
    ...
```

### <font style="color:rgb(15, 17, 21);">2. 边界更新时机错误</font>
**<font style="color:rgb(15, 17, 21);">每走完一条边，立刻更新对应边界</font>**<font style="color:rgb(15, 17, 21);">，不要等到四条都走完。</font>

<font style="color:rgb(15, 17, 21);">python</font>

```plain
# ✅ 走完 top 行，立刻 top += 1
for j in range(left, right + 1):
    res.append(matrix[top][j])
top += 1
```

### <font style="color:rgb(15, 17, 21);">3. 范围写错</font>
<font style="color:rgb(15, 17, 21);">python</font>

```plain
# ① 左到右：包含 right
range(left, right + 1)

# ② 上到下：从 top（已经 +1 过）到 bottom
range(top, bottom + 1)

# ③ 右到左：从 right（已经 -1 过）到 left，步长 -1
range(right, left - 1, -1)

# ④ 下到上：从 bottom（已经 -1 过）到 top，步长 -1
range(bottom, top - 1, -1)
```

### <font style="color:rgb(15, 17, 21);">4. 空矩阵判断</font>
<font style="color:rgb(15, 17, 21);">python</font>

```plain
if not matrix or not matrix[0]:
    return []
```

### <font style="color:rgb(15, 17, 21);">5. 循环条件写错</font>
<font style="color:rgb(15, 17, 21);">python</font>

```plain
while top <= bottom and left <= right:   # ✅
while top < bottom and left < right:     # ❌ 会漏掉最后一行/列
```

## <font style="color:rgb(15, 17, 21);">十一、模板总结</font>
```plain
def spiralOrder(matrix):
    if not matrix or not matrix[0]:
        return []
    
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    res = []
    
    while top <= bottom and left <= right:
        # ① 左 → 右
        for j in range(left, right + 1):
            res.append(matrix[top][j])
        top += 1
        
        # ② 上 → 下
        for i in range(top, bottom + 1):
            res.append(matrix[i][right])
        right -= 1
        
        # ③ 右 → 左
        if top <= bottom:
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1
        
        # ④ 下 → 上
        if left <= right:
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1
    
    return res
```

**<font style="color:rgb(15, 17, 21);">口诀：右、下、左、上；走完缩边；单行单列要判断。</font>**

## <font style="color:rgb(15, 17, 21);">一句话总结</font>
**<font style="color:rgb(15, 17, 21);">螺旋矩阵 = 四个边界向内收缩，每轮走"右→下→左→上"四条边，走完就缩边界。</font>**

+ <font style="color:rgb(15, 17, 21);">用 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top, bottom, left, right</font>`<font style="color:rgb(15, 17, 21);"> 四个变量控制边界</font>
+ <font style="color:rgb(15, 17, 21);">每走一条边，立刻更新对应边界</font>
+ **<font style="color:rgb(15, 17, 21);">③④ 前必须判断 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top <= bottom</font>**`**<font style="color:rgb(15, 17, 21);"> 和 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left <= right</font>**`<font style="color:rgb(15, 17, 21);">，防止单行/单列重复</font>
+ <font style="color:rgb(15, 17, 21);">循环条件：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">top <= bottom and left <= right</font>`

**<font style="color:rgb(15, 17, 21);">记住：外圈走完缩一圈，直到边界相交。</font>**
