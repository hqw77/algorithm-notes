# <font style="color:rgb(15, 17, 21);">滑动窗口</font>
## <font style="color:rgb(15, 17, 21);">1、什么是滑动窗口</font>
<font style="color:rgb(15, 17, 21);">滑动窗口（Sliding Window）是</font>**<font style="color:rgb(15, 17, 21);">双指针的一种特殊形式</font>**<font style="color:rgb(15, 17, 21);">：</font>

<font style="color:rgb(15, 17, 21);">用两个指针 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left</font>`<font style="color:rgb(15, 17, 21);"> 和 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right</font>`<font style="color:rgb(15, 17, 21);"> 维护一个</font>**<font style="color:rgb(15, 17, 21);">区间 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">[left, right]</font>**`<font style="color:rgb(15, 17, 21);">，这个区间就是"窗口"。通过移动左右指针，让窗口</font>**<font style="color:rgb(15, 17, 21);">滑动</font>**<font style="color:rgb(15, 17, 21);">，从而在 </font>**<font style="color:rgb(15, 17, 21);">O(n)</font>**<font style="color:rgb(15, 17, 21);"> 时间内解决子数组/子串问题。</font>

<font style="color:rgb(15, 17, 21);">核心思想：</font>**<font style="color:rgb(15, 17, 21);">右指针负责扩大窗口，左指针负责收缩窗口，避免重复计算。</font>**

## <font style="color:rgb(15, 17, 21);">2、和双指针的关系</font>
| <font style="color:rgb(15, 17, 21);">名称</font> | <font style="color:rgb(15, 17, 21);">关系</font> |
| --- | --- |
| <font style="color:rgb(15, 17, 21);">双指针</font> | <font style="color:rgb(15, 17, 21);">大类，泛指用两个指针</font> |
| <font style="color:rgb(15, 17, 21);">滑动窗口</font> | <font style="color:rgb(15, 17, 21);">双指针的子类，</font>**<font style="color:rgb(15, 17, 21);">窗口是连续的区间</font>** |
| <font style="color:rgb(15, 17, 21);">快慢指针</font> | <font style="color:rgb(15, 17, 21);">双指针的另一个子类，侧重"原地"</font> |


<font style="color:rgb(15, 17, 21);">滑动窗口特别适合</font>**<font style="color:rgb(15, 17, 21);">连续子数组 / 子串</font>**<font style="color:rgb(15, 17, 21);">问题。</font>

## <font style="color:rgb(15, 17, 21);">4、通用模板（可变长度窗口）</font>
<font style="color:rgb(15, 17, 21);">这是</font>**<font style="color:rgb(15, 17, 21);">最重要</font>**<font style="color:rgb(15, 17, 21);">的模板，覆盖 80% 的题：</font>

```plain
left = 0
for right in range(len(nums)):
    # 1. 右指针扩张：把 nums[right] 加入窗口
    加入窗口(nums[right])
    
    # 2. 判断窗口是否需要收缩
    while 窗口不满足条件:
        # 左指针收缩：把 nums[left] 移出窗口
        移出窗口(nums[left])
        left += 1
    
    # 3. 更新答案（此时窗口是合法的）
    更新答案()
```

## <font style="color:rgb(15, 17, 21);">5、类型一：固定长度窗口</font>
### <font style="color:rgb(15, 17, 21);">例题：求长度为 k 的子数组最大和</font>
<font style="color:rgb(15, 17, 21);">给数组 nums 和整数 k，求长度为 k 的连续子数组的最大和。</font>

### <font style="color:rgb(15, 17, 21);">暴力解法（O(n·k)）</font>
```plain
for i in range(len(nums) - k + 1):
    s = sum(nums[i:i+k])   # 每次都重新求和
```

### <font style="color:rgb(15, 17, 21);">滑动窗口解法（O(n)）</font>
```plain
def maxSum(nums, k):
    window_sum = sum(nums[:k])   # 第一个窗口
    max_sum = window_sum
    for i in range(k, len(nums)):
        window_sum += nums[i]        # 右边进一个
        window_sum -= nums[i-k]      # 左边出一个
        max_sum = max(max_sum, window_sum)
    return max_sum
```

### <font style="color:rgb(15, 17, 21);">图解</font>
```plain
nums = [1, 3, 2, 5, 4], k = 3

窗口1: [1, 3, 2]         sum = 6
窗口2:    [3, 2, 5]      sum = 6 + 5 - 1 = 10
窗口3:       [2, 5, 4]   sum = 10 + 4 - 3 = 11

最大和 = 11
```

**<font style="color:rgb(15, 17, 21);">关键：每次只加减一个元素，不用重新求和。</font>**

### <font style="color:rgb(15, 17, 21);">复杂度</font>

| <font style="color:rgb(15, 17, 21);">空间</font> | <font style="color:rgb(15, 17, 21);">O(1)</font> |


## <font style="color:rgb(15, 17, 21);">6、类型二：可变长度窗口</font>
### <font style="color:rgb(15, 17, 21);">例题 1：最长无重复字符子串</font>
<font style="color:rgb(15, 17, 21);">给字符串 s，找出不含重复字符的最长子串长度。</font>

### <font style="color:rgb(15, 17, 21);">思路</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right</font>`<font style="color:rgb(15, 17, 21);"> 不断右移，把字符加入窗口</font>
+ <font style="color:rgb(15, 17, 21);">如果出现重复，</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left</font>`<font style="color:rgb(15, 17, 21);"> 右移直到不重复</font>
+ <font style="color:rgb(15, 17, 21);">每次更新最大长度</font>

```plain
def lengthOfLongestSubstring(s):
    window = set()        # 记录窗口内的字符
    left = 0
    max_len = 0
    for right in range(len(s)):
        # 右扩：加入 s[right]
        while s[right] in window:     # 出现重复，收缩
            window.remove(s[left])
            left += 1
        window.add(s[right])
        max_len = max(max_len, right - left + 1)   # 更新答案
    return max_len
```

### <font style="color:rgb(15, 17, 21);">走一遍</font>
```plain
s = "abcabcbb"

right=0  'a'  窗口={a}        len=1
right=1  'b'  窗口={a,b}      len=2
right=2  'c'  窗口={a,b,c}    len=3
right=3  'a'  重复！移除 a，left=1  窗口={b,c,a}  len=3
right=4  'b'  重复！移除 b，left=2  窗口={c,a,b}  len=3
...
最大长度 = 3
```

### <font style="color:rgb(15, 17, 21);">图解</font>

### <font style="color:rgb(15, 17, 21);">例题 2：最小覆盖子串（困难）</font>
<font style="color:rgb(15, 17, 21);">在 s 中找出包含 t 所有字符的最短子串。</font>

```plain
from collections import Counter

def minWindow(s, t):
    need = Counter(t)          # 需要的字符及数量
    window = Counter()         # 窗口内的字符
    left = 0
    valid = 0                  # 已满足的字符种类数
    start, min_len = 0, float('inf')
    
    for right in range(len(s)):
        # 右扩
        c = s[right]
        if c in need:
            window[c] += 1
            if window[c] == need[c]:
                valid += 1
        
        # 左缩：当窗口已覆盖 t
        while valid == len(need):
            if right - left + 1 < min_len:
                start = left
                min_len = right - left + 1
            d = s[left]
            if d in need:
                if window[d] == need[d]:
                    valid -= 1
                window[d] -= 1
            left += 1
    
    return s[start:start+min_len] if min_len != float('inf') else ""
```

**<font style="color:rgb(15, 17, 21);">这是滑动窗口的终极形态</font>**<font style="color:rgb(15, 17, 21);">，掌握了它，其他题都不难。</font>

## <font style="color:rgb(15, 17, 21);">9、常见易错点</font>
### <font style="color:rgb(15, 17, 21);">1. 窗口收缩条件写错</font>
```plain
# ❌ 用 if 只收缩一次，可能还不够
if 窗口不合法:
    ...

# ✅ 用 while 一直收缩到合法
while 窗口不合法:
    ...
```

### <font style="color:rgb(15, 17, 21);">2. 更新答案的时机</font>
```plain
# 有的题在收缩前更新，有的在收缩后
# 最长子串 → 窗口合法时更新
# 最短子串 → 窗口合法时先更新，再收缩
```

**<font style="color:rgb(15, 17, 21);">看题目要求：求最长就尽量保持窗口大，求最短就尽量收缩。</font>**

### <font style="color:rgb(15, 17, 21);">3. 忘记处理边界</font>
```plain
if not s or not t:
    return ""
```

### <font style="color:rgb(15, 17, 21);">4. 左右指针含义混淆</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left</font>`<font style="color:rgb(15, 17, 21);">：窗口左边界（收缩用）</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right</font>`<font style="color:rgb(15, 17, 21);">：窗口右边界（扩张用）</font>
+ <font style="color:rgb(15, 17, 21);">窗口长度 = </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right - left + 1</font>`

### <font style="color:rgb(15, 17, 21);">5. 只移动 right 不移动 left</font>
<font style="color:rgb(15, 17, 21);">变长窗口</font>**<font style="color:rgb(15, 17, 21);">必须两个都动</font>**<font style="color:rgb(15, 17, 21);">，否则窗口无法收缩。</font>

## <font style="color:rgb(15, 17, 21);">10、模板总结</font>
### <font style="color:rgb(15, 17, 21);">模板一：固定窗口</font>
```plain
window = sum(nums[:k])
ans = window
for i in range(k, len(nums)):
    window += nums[i] - nums[i-k]
    ans = max(ans, window)
```

### <font style="color:rgb(15, 17, 21);">模板二：变长窗口（求最长）</font>
```plain
left = 0
ans = 0
for right in range(len(nums)):
    加入 nums[right]
    while 窗口不合法:
        移除 nums[left]
        left += 1
    ans = max(ans, right - left + 1)   # 合法时更新
```

### <font style="color:rgb(15, 17, 21);">模板三：变长窗口（求最短）</font>
```plain
left = 0
ans = float('inf')
for right in range(len(nums)):
    加入 nums[right]
    while 窗口合法:
        ans = min(ans, right - left + 1)   # 合法时更新
        移除 nums[left]
        left += 1
```
