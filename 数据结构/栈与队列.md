# 栈与队列

## 什么是栈与队列

- **栈（Stack）**：后进先出（LIFO），像叠盘子，只能操作顶部。
- **队列（Queue）**：先进先出（FIFO），像排队，队尾进、队首出。

## Python 实现

```python
# 栈 —— 用 list
stack = []
stack.append(x)   # 入栈
stack.pop()       # 出栈（返回栈顶）
stack[-1]         # 看栈顶（不弹出）

# 队列 —— 用 deque（list 头删是 O(n)，deque 是 O(1)）
from collections import deque
q = deque()
q.append(x)       # 入队（右侧）
q.popleft()       # 出队（左侧），O(1)
```

## 核心技巧：单调栈

单调栈是栈的进阶应用：**栈内元素保持单调**（递增或递减）。遇到新元素时，把「破坏单调性」的栈顶弹出，从而在 **O(n)** 时间内求出每个元素的「下一个更大 / 更小元素」。

## 模板

### 模板一：栈匹配括号

```python
def isValid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in pairs.values():        # 左括号入栈
            stack.append(c)
        else:                          # 右括号匹配
            if not stack or stack.pop() != pairs[c]:
                return False
    return not stack                   # 栈空才算全部匹配
```

### 模板二：单调栈（下一个更大元素）

```python
def nextGreater(nums):
    n = len(nums)
    ans = [-1] * n
    stack = []                       # 存下标，栈内值单调递减
    for i in range(n):
        while stack and nums[i] > nums[stack[-1]]:
            idx = stack.pop()
            ans[idx] = nums[i]       # nums[i] 是 idx 的下一个更大
        stack.append(i)
    return ans
```

### 模板三：队列层序遍历（BFS）

```python
from collections import deque
q = deque([start])
while q:
    cur = q.popleft()
    for nxt in 邻居(cur):
        q.append(nxt)
```

## 例题（hot100）

### 例题 1：有效的括号（LeetCode 20）

**题目**：判断括号字符串是否合法。`"()[]{}"` 合法，`"([)]"` 不合法。

```python
def isValid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for c in s:
        if c in '([{':
            stack.append(c)
        else:
            if not stack or stack.pop() != pairs[c]:
                return False
    return not stack
```

#### 图解

遇到右括号时，栈顶必须是对应的左括号，弹出；最后栈空才合法。

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(n) |

---

### 例题 2：每日温度（LeetCode 739）

**题目**：返回数组，表示要等几天才能遇到更高温度（没有则为 0）。

例：`[73,74,75,71,69,72,76,73]` → `[1,1,4,2,1,1,0,0]`

```python
def dailyTemperatures(temperatures):
    n = len(temperatures)
    ans = [0] * n
    stack = []                       # 单调递减栈，存下标
    for i, t in enumerate(temperatures):
        while stack and t > temperatures[stack[-1]]:
            idx = stack.pop()
            ans[idx] = i - idx       # 天数差
        stack.append(i)
    return ans
```

#### 图解

当前温度比栈顶高时，弹出栈顶并算出等待天数（当前下标 - 栈顶下标）。

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n)（每个元素入栈出栈各一次） |
| 空间 | O(n) |

---

### 例题 3：最小栈（LeetCode 155）

**题目**：设计一个栈，支持 `push / pop / top / getMin`，`getMin` 返回栈内最小值，要求 **O(1)**。

#### 思路

用**辅助栈**同步记录「当前位置的最小值」。

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, x):
        self.stack.append(x)
        cur_min = min(x, self.min_stack[-1] if self.min_stack else x)
        self.min_stack.append(cur_min)

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | 所有操作 O(1) |
| 空间 | O(n) |

## 识别信号

- ✅ **括号匹配**、**最近相关性**、**撤销 / 回溯** → 栈
- ✅ **下一个更大 / 更小元素**、**柱状图 / 矩形面积** → 单调栈
- ✅ **先进先出**、**层序遍历 / BFS** → 队列

## 常见易错点

1. **栈空时 pop**：先判断 `if stack` 或 `if not stack`。
2. **单调栈存下标还是值**：一般存下标，方便算距离；只存值则只能比较。
3. **单调栈方向记反**：递减栈找「下一个更大」，递增栈找「下一个更小」。
4. **队列用 list 头删**：`list.pop(0)` 是 O(n)，用 `deque.popleft()` 才是 O(1)。
5. **括号匹配最后**：要 `return not stack`（栈空才合法），不是直接 return True。

## 一句话总结

**栈 = 后进先出，解决「括号 / 最近相关 / 单调」问题；队列 = 先进先出，用于 BFS 层序；单调栈是「下一个更大 / 更小」的杀手锏。**
