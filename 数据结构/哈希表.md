# 哈希表

## 什么是哈希表

哈希表（Hash Table / 散列表）是一种通过**哈希函数**把键（key）映射到存储位置的**键值对**数据结构。

核心价值：**查找、插入、删除的平均时间复杂度都是 O(1)**。

- 普通数组查找一个元素要 O(n)（线性扫）
- 哈希表通过哈希函数直接算出位置，**O(1) 定位**

代价是**空间换时间**：需要额外存储，且键是无序的。

## Python 里的哈希表

```python
# 1. 字典 dict —— 存「键 -> 值」
d = {}
d['a'] = 1
d.get('a', 0)      # 取值，键不存在时返回默认值 0
'a' in d           # 判断键是否存在，O(1)

# 2. 集合 set —— 只存键，用于去重 / 判断存在
s = set()
s.add(1)
1 in s             # O(1)

# 3. 计数器 Counter —— 统计频率（本质是 dict 子类）
from collections import Counter
c = Counter([1, 1, 2, 3])
c[1]               # 2

# 4. 默认字典 defaultdict —— 键不存在时自动给默认值，省去初始化
from collections import defaultdict
d = defaultdict(list)
d['key'].append(1)   # 不存在时自动创建空列表，不会 KeyError
```

## 哈希表能解决什么

| 用途 | 用什么 | 典型场景 |
| --- | --- | --- |
| 判断存在 | set | 是否重复、是否出现过 |
| 计数 / 频率 | dict / Counter | 出现次数、最多/最少的元素 |
| 去重 | set | 去除重复元素 |
| 建立映射 | dict | 元素 → 下标、元素 → 分组 |
| 缓存 | dict | 记忆化搜索、避免重复计算 |

## 核心套路：边遍历边查表

hot100 里哈希题最高频的思想是——**遍历的同时，把「当前值」和「目标关系」存进表里，后续 O(1) 查询**。

经典公式：

```python
if target - x in seen:   # 当前值 x，找它的"另一半" target - x
    ...
```

## 模板

### 模板一：配对查找（两数之和类）

```python
def twoSum(nums, target):
    seen = {}                  # 值 -> 下标
    for i, x in enumerate(nums):
        if target - x in seen: # 先查"另一半"是否出现过
            return [seen[target - x], i]
        seen[x] = i            # 没找到就把当前值存进去
    return []
```

### 模板二：计数统计

```python
from collections import Counter
cnt = Counter(nums)
for x, c in cnt.items():
    # x 是元素，c 是它出现的次数
    ...
```

### 模板三：分组（归类）

```python
from collections import defaultdict
groups = defaultdict(list)
for item in items:
    key = 某种规则(item)      # 把 item 转成代表"同一类"的 key
    groups[key].append(item)
# 最终 groups.values() 就是分组结果
```

### 模板四：哈希集合去重 + 存在性

```python
seen = set()
for x in nums:
    if x in seen:
        ...                 # 已出现过
    seen.add(x)
```

## 例题（hot100）

### 例题 1：两数之和（LeetCode 1）

**题目**：给定整数数组 `nums` 和目标整数 `target`，找出和为 `target` 的两个数的**下标**。假设只有一个答案，且同一元素不能重复使用。

#### 暴力解法（O(n²)）

```python
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):
        if nums[i] + nums[j] == target:
            return [i, j]
```

每个数都和其他所有数试一遍，慢。

#### 哈希表解法（O(n)）

```python
def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []
```

#### 走一遍

```plain
nums = [2, 7, 11, 15], target = 9

i=0  x=2   找 7  不在 seen   → seen = {2: 0}
i=1  x=7   找 2  在！         → 返回 [0, 1]
```

#### 为什么是"边遍历边存"？

因为答案的两个数，**后遍历到的那个，能立刻在表里查到先遍历的那个**。不需要先把全部存好再找。

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(n) |

### 例题 2：字母异位词分组（LeetCode 49）

**题目**：给定字符串数组 `strs`，把**字母异位词**（字母相同、排列不同）分到同一组。

例：`["eat", "tea", "tan", "ate", "nat", "bat"]`
→ `[["eat","tea","ate"], ["tan","nat"], ["bat"]]`

#### 思路

异位词的本质是「字母的计数一样」。最简单的方式：**排序后字符串相同**。

`"eat"` 和 `"tea"` 排序后都是 `"aet"` → 用排序结果当 key 分组。

#### 代码

```python
from collections import defaultdict

def groupAnagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = ''.join(sorted(s))   # 排序后作为 key
        groups[key].append(s)
    return list(groups.values())
```

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n·k log k)，n 是字符串个数，k 是单个字符串长度 |
| 空间 | O(n·k) |

> 进阶：key 也可以用「26 个字母的计数元组」，把排序的 k log k 降到 k，但代码更繁琐。面试提一句即可。

### 例题 3：最长连续序列（LeetCode 128）

**题目**：给定**未排序**的整数数组 `nums`，找出最长连续序列的长度，要求 **O(n)**。

例：`nums = [100, 4, 200, 1, 3, 2]` → 最长连续序列是 `[1,2,3,4]`，返回 `4`。

#### 思路

1. 先用 `set` 去重，O(1) 判断某个数是否存在。
2. 关键优化：**只从"序列起点"开始数**——当 `x - 1` 不存在于集合中时，`x` 才是一个连续序列的起点。

这样每个序列只会被数一次，避免 O(n²) 的重复。

#### 代码

```python
def longestConsecutive(nums):
    s = set(nums)
    ans = 0
    for x in s:
        if x - 1 not in s:        # 只从起点开始数
            cur = x
            length = 1
            while cur + 1 in s:   # 往后数连续
                cur += 1
                length += 1
            ans = max(ans, length)
    return ans
```

#### 图解

```plain
nums = [100, 4, 200, 1, 3, 2]
s = {100, 4, 200, 1, 3, 2}

x=100  99 不在 → 起点，往后数 101 不在 → 长度 1
x=4    3 在    → 不是起点，跳过
x=200  199 不在 → 起点，数 201 不在 → 长度 1
x=1    0 不在 → 起点，数 2、3、4 都在 → 长度 4  ← 最长
x=3    2 在    → 跳过
x=2    1 在    → 跳过
```

#### 为什么只数起点就 O(n)？

每个元素最多被「往后数」的 while 循环访问一次。如果每个数都数，`[1,2,3,4]` 会被数 4 次，变 O(n²)。

#### 复杂度

| 指标 | 值 |
| --- | --- |
| 时间 | O(n)（每个元素只被访问常数次） |
| 空间 | O(n)（集合存储） |

## 识别信号

看到以下关键词，优先考虑哈希表：

- ✅ **判断是否存在 / 是否重复**
- ✅ **统计出现次数 / 频率 / 最多最少**
- ✅ **两数之和 / 配对 / 找 target**
- ✅ **分组 / 归类**
- ✅ **去重**
- ✅ **要求 O(1) 查找**，或**要求 O(n) 时间**（用空间换时间）

## 常见易错点

1. **存值还是存下标搞混**：两数之和要返回下标，所以存 `值 -> 下标`；如果只要判断存在，用 set 就行。
2. **插入时机**：两数之和要**边遍历边插入**，先全插进去会导致重复使用同一元素。
3. **忘记去重**：最长连续序列先 `set` 去重，否则重复元素会干扰。
4. **KeyError**：直接 `d[k]` 取值，键不存在会报错；用 `d.get(k, 默认)` 或 `defaultdict`。
5. **O(1) 是平均复杂度**：哈希冲突严重时最坏 O(n)，但 Python 的 dict 处理得好，日常可视为 O(1)。

## 模板总结（速查）

| 场景 | 模板 |
| --- | --- |
| 配对查找 | `if target - x in seen` 边遍历边存 |
| 计数 | `Counter(nums)` |
| 分组 | `defaultdict(list)` + key 归类 |
| 去重 / 存在性 | `set` + `x in s` |

## 一句话总结

**哈希表 = 空间换时间，把 O(n) 查找降到 O(1)；核心套路是"边遍历边查表"——用 `set` 判存在，用 `dict` 存映射和计数。**
