# 双指针
## <font style="color:rgb(15, 17, 21);">什么是双指针</font>
<font style="color:rgb(15, 17, 21);">双指针（Two Pointers）不是一种具体的数据结构，而是一种</font>**<font style="color:rgb(15, 17, 21);">算法思想</font>**<font style="color:rgb(15, 17, 21);">：</font>

<font style="color:rgb(15, 17, 21);">在数组、字符串或链表上，用</font>**<font style="color:rgb(15, 17, 21);">两个指针</font>**<font style="color:rgb(15, 17, 21);">（通常是索引）按照某种规则移动，从而在 </font>**<font style="color:rgb(15, 17, 21);">O(n)</font>**<font style="color:rgb(15, 17, 21);"> 时间内解决问题。</font>

<font style="color:rgb(15, 17, 21);">两个指针可以是：</font>

+ **<font style="color:rgb(15, 17, 21);">同向移动</font>**<font style="color:rgb(15, 17, 21);">（快慢指针）</font>
+ **<font style="color:rgb(15, 17, 21);">相向移动</font>**<font style="color:rgb(15, 17, 21);">（左右夹逼）</font>
+ **<font style="color:rgb(15, 17, 21);">分别指向两个序列</font>**<font style="color:rgb(15, 17, 21);">（归并思想）</font>

<font style="color:rgb(15, 17, 21);">核心价值：</font>**<font style="color:rgb(15, 17, 21);">把暴力解法的 O(n²) 优化到 O(n)。</font>**

## <font style="color:rgb(15, 17, 21);">双指针的三种常见类型</font>
| <font style="color:rgb(15, 17, 21);">类型</font> | <font style="color:rgb(15, 17, 21);">移动方式</font> | <font style="color:rgb(15, 17, 21);">典型场景</font> |
| --- | --- | --- |
| <font style="color:rgb(15, 17, 21);">同向（快慢）</font> | <font style="color:rgb(15, 17, 21);">都从左往右，速度不同</font> | <font style="color:rgb(15, 17, 21);">去重、删除元素、判断环</font> |
| <font style="color:rgb(15, 17, 21);">相向（左右夹逼）</font> | <font style="color:rgb(15, 17, 21);">一个从左、一个从右，向中间靠</font> | <font style="color:rgb(15, 17, 21);">有序数组两数之和、回文串</font> |
| <font style="color:rgb(15, 17, 21);">分离（双序列）</font> | <font style="color:rgb(15, 17, 21);">各指一个序列</font> | <font style="color:rgb(15, 17, 21);">归并两个有序数组</font> |


### <font style="color:rgb(15, 17, 21);">类型一：相向双指针（左右夹逼）</font>
#### <font style="color:rgb(15, 17, 21);">适用条件</font>
**<font style="color:rgb(15, 17, 21);">数组必须有序</font>**<font style="color:rgb(15, 17, 21);">（或能排序）。</font>

#### <font style="color:rgb(15, 17, 21);">经典例题：两数之和 II（有序数组）</font>
<font style="color:rgb(15, 17, 21);">在</font>**<font style="color:rgb(15, 17, 21);">升序数组</font>**<font style="color:rgb(15, 17, 21);">中找到两个数，使它们的和等于 target，返回索引。</font>

#### <font style="color:rgb(15, 17, 21);">暴力解法（O(n²)）</font>
```plain
for i in range(len(nums)):
    for j in range(i+1, len(nums)):
        if nums[i] + nums[j] == target:
            return [i, j]
```

<font style="color:rgb(15, 17, 21);">每个数都和其他所有数试一遍，慢。</font>

#### <font style="color:rgb(15, 17, 21);">双指针解法（O(n)）</font>
```plain
def twoSum(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            return [left, right]
        elif s < target:
            left += 1      # 和太小，左指针右移让和变大
        else:
            right -= 1     # 和太大，右指针左移让和变小
    return []
```

#### <font style="color:rgb(15, 17, 21);">为什么这样能行？</font>
<font style="color:rgb(15, 17, 21);">利用</font>**<font style="color:rgb(15, 17, 21);">有序性</font>**<font style="color:rgb(15, 17, 21);">：</font>

```plain
nums = [1, 2, 4, 7, 11, 15]   target = 9

left=0(1)  right=5(15)  sum=16 > 9  → right--   （15太大，排除）
left=0(1)  right=4(11)  sum=12 > 9  → right--
left=0(1)  right=3(7)   sum=8  < 9  → left++    （1太小，排除）
left=1(2)  right=3(7)   sum=9  = 9  → 找到！
```

**<font style="color:rgb(15, 17, 21);">关键推理：</font>**

+ <font style="color:rgb(15, 17, 21);">如果 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">sum < target</font>`<font style="color:rgb(15, 17, 21);">，说明左边的数太小了，</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left</font>`<font style="color:rgb(15, 17, 21);"> 右移</font>
+ <font style="color:rgb(15, 17, 21);">如果 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">sum > target</font>`<font style="color:rgb(15, 17, 21);">，说明右边的数太大了，</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right</font>`<font style="color:rgb(15, 17, 21);"> 左移</font>
+ <font style="color:rgb(15, 17, 21);">每次移动都</font>**<font style="color:rgb(15, 17, 21);">排除掉一个不可能的数</font>**<font style="color:rgb(15, 17, 21);">，所以最多移动 n 次</font>

#### <font style="color:rgb(15, 17, 21);">图解</font>
```plain
[1, 2, 4, 7, 11, 15]
 L                R      sum=16>9  R--
 L            R         sum=12>9  R--
 L        R            sum=8<9   L++
    L     R            sum=9=9  找到！
```

#### <font style="color:rgb(15, 17, 21);">复杂度</font>
| <font style="color:rgb(15, 17, 21);">指标</font> | <font style="color:rgb(15, 17, 21);">值</font> |
| --- | --- |
| <font style="color:rgb(15, 17, 21);">时间</font> | <font style="color:rgb(15, 17, 21);">O(n)</font> |
| <font style="color:rgb(15, 17, 21);">空间</font> | <font style="color:rgb(15, 17, 21);">O(1)</font> |

### <font style="color:rgb(15, 17, 21);">类型二：同向双指针（快慢指针）</font>
#### <font style="color:rgb(15, 17, 21);">适用场景</font>
+ <font style="color:rgb(15, 17, 21);">原地删除/移动元素</font>
+ <font style="color:rgb(15, 17, 21);">数组去重</font>
+ <font style="color:rgb(15, 17, 21);">判断链表是否有环</font>

#### <font style="color:rgb(15, 17, 21);">经典例题：原地删除重复元素</font>
<font style="color:rgb(15, 17, 21);">给一个</font>**<font style="color:rgb(15, 17, 21);">有序数组</font>**<font style="color:rgb(15, 17, 21);">，原地删除重复元素，返回新长度。</font>

#### <font style="color:rgb(15, 17, 21);">思路</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">slow</font>`<font style="color:rgb(15, 17, 21);">：指向已处理好的部分的末尾</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">fast</font>`<font style="color:rgb(15, 17, 21);">：负责探路，找新元素</font>

```plain
def removeDuplicates(nums):
    if not nums:
        return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:   # 发现新元素
            slow += 1
            nums[slow] = nums[fast]    # 搬到 slow 后面
    return slow + 1
```

#### <font style="color:rgb(15, 17, 21);">走一遍</font>
```plain
nums = [1, 1, 2, 2, 3]

slow=0
fast=1  nums[1]=1 == nums[0]=1  → 跳过
fast=2  nums[2]=2 != nums[0]=1  → slow=1, nums[1]=2
fast=3  nums[3]=2 == nums[1]=2  → 跳过
fast=4  nums[4]=3 != nums[1]=2  → slow=2, nums[2]=3

结果 nums = [1, 2, 3]  新长度 = 3
```

#### <font style="color:rgb(15, 17, 21);">图解</font>
```plain
[1, 1, 2, 2, 3]
 S  F              相同，F++
 S     F           不同，S++, 搬过来
       S  F        相同，F++
       S     F     不同，S++, 搬过来
             S     完成，长度 = S+1 = 3
```

#### <font style="color:rgb(15, 17, 21);">复杂度</font>
| <font style="color:rgb(15, 17, 21);">指标</font> | <font style="color:rgb(15, 17, 21);">值</font> |
| --- | --- |
| <font style="color:rgb(15, 17, 21);">时间</font> | <font style="color:rgb(15, 17, 21);">O(n)</font> |
| <font style="color:rgb(15, 17, 21);">空间</font> | <font style="color:rgb(15, 17, 21);">O(1)</font> |

### <font style="color:rgb(15, 17, 21);">类型三：分离双指针（双序列）</font>
#### <font style="color:rgb(15, 17, 21);">适用场景</font>
+ <font style="color:rgb(15, 17, 21);">合并两个有序数组</font>
+ <font style="color:rgb(15, 17, 21);">求两个数组的交集</font>
+ <font style="color:rgb(15, 17, 21);">归并排序的合并步骤</font>

#### <font style="color:rgb(15, 17, 21);">经典例题：合并两个有序数组</font>
```plain
def merge(nums1, nums2):
    i = j = 0
    res = []
    while i < len(nums1) and j < len(nums2):
        if nums1[i] <= nums2[j]:
            res.append(nums1[i])
            i += 1
        else:
            res.append(nums2[j])
            j += 1
    # 处理剩余部分
    res.extend(nums1[i:])
    res.extend(nums2[j:])
    return res
```

<font style="color:rgb(15, 17, 21);">两个指针各指一个数组，谁小先放谁。</font>

## <font style="color:rgb(15, 17, 21);">进阶：三数之和</font>
<font style="color:rgb(15, 17, 21);">双指针最经典的综合应用。</font>

<font style="color:rgb(15, 17, 21);">找出数组中所有和为 0 的三元组，不能重复。</font>

#### <font style="color:rgb(15, 17, 21);">思路</font>
<font style="color:rgb(15, 17, 21);">固定一个数，剩下两个数用</font>**<font style="color:rgb(15, 17, 21);">相向双指针</font>**<font style="color:rgb(15, 17, 21);">找。</font>

```plain
def threeSum(nums):
    nums.sort()
    res = []
    n = len(nums)
    for i in range(n - 2):
        if nums[i] > 0:              # 最小的都大于0，后面不可能
            break
        if i > 0 and nums[i] == nums[i-1]:   # 跳过重复的固定数
            continue
        left, right = i + 1, n - 1
        while left < right:
            s = nums[i] + nums[left] + nums[right]
            if s == 0:
                res.append([nums[i], nums[left], nums[right]])
                # 跳过重复
                while left < right and nums[left] == nums[left+1]:
                    left += 1
                while left < right and nums[right] == nums[right-1]:
                    right -= 1
                left += 1
                right -= 1
            elif s < 0:
                left += 1
            else:
                right -= 1
    return res
```

#### <font style="color:rgb(15, 17, 21);">关键点</font>
1. **<font style="color:rgb(15, 17, 21);">先排序</font>**<font style="color:rgb(15, 17, 21);">，才能用双指针</font>
2. **<font style="color:rgb(15, 17, 21);">固定一个数 i</font>**<font style="color:rgb(15, 17, 21);">，剩下两数用左右指针找</font>
3. **<font style="color:rgb(15, 17, 21);">去重</font>**<font style="color:rgb(15, 17, 21);">：固定数去重 + 左右指针去重</font>

#### <font style="color:rgb(15, 17, 21);">复杂度</font>
<font style="color:rgb(15, 17, 21);">O(n²)：外层 n 次，内层双指针 O(n)。</font>

## <font style="color:rgb(15, 17, 21);">双指针的识别信号</font>
<font style="color:rgb(15, 17, 21);">看到以下关键词，考虑双指针：</font>

+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">数组有序</font>**<font style="color:rgb(15, 17, 21);"> → 相向双指针</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">原地修改</font>**<font style="color:rgb(15, 17, 21);"> → 快慢指针</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">两数/三数之和</font>**<font style="color:rgb(15, 17, 21);"> → 相向双指针</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">删除/移动元素</font>**<font style="color:rgb(15, 17, 21);"> → 快慢指针</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">合并有序序列</font>**<font style="color:rgb(15, 17, 21);"> → 分离双指针</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">回文判断</font>**<font style="color:rgb(15, 17, 21);"> → 相向双指针</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">链表找环/中点</font>**<font style="color:rgb(15, 17, 21);"> → 快慢指针</font>

## <font style="color:rgb(15, 17, 21);">常见易错点</font>
### <font style="color:rgb(15, 17, 21);">1. 指针移动条件写反</font>
```plain
if s < target:
    left += 1     # 和太小 → 左指针右移（增大）
else:
    right -= 1    # 和太大 → 右指针左移（减小）
```

### <font style="color:rgb(15, 17, 21);">2. 循环条件用错</font>
<font style="color:rgb(15, 17, 21);">相向双指针用 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">while left < right</font>`<font style="color:rgb(15, 17, 21);">，</font>**<font style="color:rgb(15, 17, 21);">不能用 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);"><=</font>**`<font style="color:rgb(15, 17, 21);">（会自己和自己配对）。</font>

### <font style="color:rgb(15, 17, 21);">3. 忘记去重</font>
<font style="color:rgb(15, 17, 21);">三数之和、四数之和必须处理重复，否则结果有重复三元组。</font>

### <font style="color:rgb(15, 17, 21);">4. 忘记排序</font>
<font style="color:rgb(15, 17, 21);">相向双指针</font>**<font style="color:rgb(15, 17, 21);">强依赖有序性</font>**<font style="color:rgb(15, 17, 21);">，用之前先 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">nums.sort()</font>`<font style="color:rgb(15, 17, 21);">。</font>

### <font style="color:rgb(15, 17, 21);">5. 边界处理</font>
```plain
if not nums:      # 空数组
    return []
```

## <font style="color:rgb(15, 17, 21);">模板总结</font>
### <font style="color:rgb(15, 17, 21);">模板一：相向双指针</font>
```plain
left, right = 0, len(nums) - 1
while left < right:
    # 根据条件移动 left 或 right
    if 条件:
        left += 1
    else:
        right -= 1
```

### <font style="color:rgb(15, 17, 21);">模板二：快慢指针</font>
```plain
slow = 0
for fast in range(len(nums)):
    if 满足条件:
        nums[slow] = nums[fast]
        slow += 1
return slow
```

### <font style="color:rgb(15, 17, 21);">模板三：分离双指针</font>
```plain
i = j = 0
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        # 处理 a[i]
        i += 1
    else:
        # 处理 b[j]
        j += 1
```
