# 滑动窗口
## 1,什么是滑动窗口
滑动窗口(Sliding Window)是**双指针的一种特殊形式**:

用两个指针 `left` 和 `right` 维护一个**区间 **`**[left, right]**`,这个区间就是"窗口".通过移动左右指针,让窗口**滑动**,从而在 **O(n)** 时间内解决子数组/子串问题.

核心思想:**右指针负责扩大窗口,左指针负责收缩窗口,避免重复计算.**

## 2,和双指针的关系
| 名称 | 关系 |
| --- | --- |
| 双指针 | 大类,泛指用两个指针 |
| 滑动窗口 | 双指针的子类,**窗口是连续的区间** |
| 快慢指针 | 双指针的另一个子类,侧重"原地" |


滑动窗口特别适合**连续子数组 / 子串**问题.

## 3,滑动窗口的两种类型
| 类型 | 特点 | 典型场景 |
| --- | --- | --- |
| **固定长度窗口** | 窗口大小固定为 k | 求长度为 k 的子数组最大和 |
| **可变长度窗口** | 窗口大小动态变化 | 最长无重复子串,最小覆盖子串 |


## 4,通用模板(可变长度窗口)
这是**最重要**的模板,覆盖 80% 的题:

```plain
left = 0
for right in range(len(nums)):
    # 1. 右指针扩张:把 nums[right] 加入窗口
    加入窗口(nums[right])
    
    # 2. 判断窗口是否需要收缩
    while 窗口不满足条件:
        # 左指针收缩:把 nums[left] 移出窗口
        移出窗口(nums[left])
        left += 1
    
    # 3. 更新答案(此时窗口是合法的)
    更新答案()
```

## 5,类型一:固定长度窗口
### 例题:求长度为 k 的子数组最大和
给数组 nums 和整数 k,求长度为 k 的连续子数组的最大和.

### 暴力解法(O(n*k))
```plain
for i in range(len(nums) - k + 1):
    s = sum(nums[i:i+k])   # 每次都重新求和
```

### 滑动窗口解法(O(n))
```plain
def maxSum(nums, k):
    window_sum = sum(nums[:k])   # 第一个窗口
    max_sum = window_sum
    for i in range(k, len(nums)):
        window_sum += nums[i]        # 右边进一个
        window_sum -= nums[i-k]      # 左边出一个
        max_sum = max(max_sum, window_sum)
    return max_sum
```

### 图解
```plain
nums = [1, 3, 2, 5, 4], k = 3

窗口1: [1, 3, 2]         sum = 6
窗口2:    [3, 2, 5]      sum = 6 + 5 - 1 = 10
窗口3:       [2, 5, 4]   sum = 10 + 4 - 3 = 11

最大和 = 11
```

**关键:每次只加减一个元素,不用重新求和.**

### 复杂度
| 指标 | 值 |
| --- | --- |
| 时间 | O(n) |
| 空间 | O(1) |


## 6,类型二:可变长度窗口
### 例题 1:最长无重复字符子串
给字符串 s,找出不含重复字符的最长子串长度.

### 思路
+ `right` 不断右移,把字符加入窗口
+ 如果出现重复,`left` 右移直到不重复
+ 每次更新最大长度

```plain
def lengthOfLongestSubstring(s):
    window = set()        # 记录窗口内的字符
    left = 0
    max_len = 0
    for right in range(len(s)):
        # 右扩:加入 s[right]
        while s[right] in window:     # 出现重复,收缩
            window.remove(s[left])
            left += 1
        window.add(s[right])
        max_len = max(max_len, right - left + 1)   # 更新答案
    return max_len
```

### 走一遍
```plain
s = "abcabcbb"

right=0  'a'  窗口={a}        len=1
right=1  'b'  窗口={a,b}      len=2
right=2  'c'  窗口={a,b,c}    len=3
right=3  'a'  重复!移除 a,left=1  窗口={b,c,a}  len=3
right=4  'b'  重复!移除 b,left=2  窗口={c,a,b}  len=3
...
最大长度 = 3
```

### 图解
```plain
"a b c a b c b b"
 L
 R                 窗口 {a}       len=1
 L
   R               窗口 {a,b}     len=2
 L
     R             窗口 {a,b,c}   len=3
   L
     R             重复a,L右移   窗口 {b,c,a}
   L
       R           重复b,L右移   窗口 {c,a,b}
       ...
```

### 复杂度
| 指标 | 值 |
| --- | --- |
| 时间 | O(n)(每个字符最多进出窗口一次) |
| 空间 | O(字符集大小) |

### 例题 2:最小覆盖子串(困难)
在 s 中找出包含 t 所有字符的最短子串.

```plain
from collections import Counter

def minWindow(s, t):
    need = Counter(t)          # 需要的字符及数量
    window = Counter()         # 窗口内的字符
    left = 0
    valid = 0                  # 已满足的字符种类数
    start, min_len = 0, float('inf')
    
    for right in range(len(s)):
        # 右扩
        c = s[right]
        if c in need:
            window[c] += 1
            if window[c] == need[c]:
                valid += 1
        
        # 左缩:当窗口已覆盖 t
        while valid == len(need):
            if right - left + 1 < min_len:
                start = left
                min_len = right - left + 1
            d = s[left]
            if d in need:
                if window[d] == need[d]:
                    valid -= 1
                window[d] -= 1
            left += 1
    
    return s[start:start+min_len] if min_len != float('inf') else ""
```

**这是滑动窗口的终极形态**,掌握了它,其他题都不难.

## 7,滑动窗口的识别信号
看到以下关键词,考虑滑动窗口:

+ ✅ **连续子数组 / 子串**
+ ✅ **最长 / 最短 / 最大 / 最小**
+ ✅ **满足某条件的连续区间**
+ ✅ **不重复 / 包含某些字符**
+ ✅ **固定长度 k**

**反例(不能用滑动窗口):**

+ ❌ 子序列(不连续)
+ ❌ 数组无序且需要排序
+ ❌ 求"所有"组合

## 八,滑动窗口 vs 其他方法
| 方法 | 时间 | 适用 |
| --- | --- | --- |
| 暴力枚举所有子数组 | O(n^2) 或 O(n^3) | 保底 |
| **滑动窗口** | **O(n)** | 连续区间 |
| 前缀和 | O(n) | 区间求和 |
| 哈希表 | O(n) | 无序配对 |

## 9,常见易错点
### 1. 窗口收缩条件写错
```plain
# ❌ 用 if 只收缩一次,可能还不够
if 窗口不合法:
    ...

# ✅ 用 while 一直收缩到合法
while 窗口不合法:
    ...
```

### 2. 更新答案的时机
```plain
# 有的题在收缩前更新,有的在收缩后
# 最长子串 -> 窗口合法时更新
# 最短子串 -> 窗口合法时先更新,再收缩
```

**看题目要求:求最长就尽量保持窗口大,求最短就尽量收缩.**

### 3. 忘记处理边界
```plain
if not s or not t:
    return ""
```

### 4. 左右指针含义混淆
+ `left`:窗口左边界(收缩用)
+ `right`:窗口右边界(扩张用)
+ 窗口长度 = `right - left + 1`

### 5. 只移动 right 不移动 left
变长窗口**必须两个都动**,否则窗口无法收缩.

## 10,模板总结
### 模板一:固定窗口
```plain
window = sum(nums[:k])
ans = window
for i in range(k, len(nums)):
    window += nums[i] - nums[i-k]
    ans = max(ans, window)
```

### 模板二:变长窗口(求最长)
```plain
left = 0
ans = 0
for right in range(len(nums)):
    加入 nums[right]
    while 窗口不合法:
        移除 nums[left]
        left += 1
    ans = max(ans, right - left + 1)   # 合法时更新
```

### 模板三:变长窗口(求最短)
```plain
left = 0
ans = float('inf')
for right in range(len(nums)):
    加入 nums[right]
    while 窗口合法:
        ans = min(ans, right - left + 1)   # 合法时更新
        移除 nums[left]
        left += 1
```
