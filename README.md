## 使用方式

1. 按学习路线顺序阅读各主题笔记。
2. 每学完一个主题，到 [高频题单](刷题/高频题单.md) 挑对应题目练习。
3. 复习时用 [模板速查](模板/模板速查.md) 快速回顾各算法模板。
4. 完整目录见 [SUMMARY.md](SUMMARY.md)。
