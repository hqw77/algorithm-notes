# <font style="color:rgb(15, 17, 21);">二分查找</font>
## <font style="color:rgb(15, 17, 21);">什么是二分查找</font>
<font style="color:rgb(15, 17, 21);">二分查找（Binary Search）是一种在</font>**<font style="color:rgb(15, 17, 21);">有序数据</font>**<font style="color:rgb(15, 17, 21);">中快速查找目标的算法：</font>

<font style="color:rgb(15, 17, 21);">每次取中间元素和目标比较，</font>**<font style="color:rgb(15, 17, 21);">排除一半</font>**<font style="color:rgb(15, 17, 21);">不可能的范围，不断缩小查找区间，直到找到目标或区间为空。</font>

<font style="color:rgb(15, 17, 21);">核心价值：把 </font>**<font style="color:rgb(15, 17, 21);">O(n)</font>**<font style="color:rgb(15, 17, 21);"> 的线性查找优化到 </font>**<font style="color:rgb(15, 17, 21);">O(log n)</font>**<font style="color:rgb(15, 17, 21);">。</font>

<font style="color:rgb(15, 17, 21);">比如 100 万个数据，线性查找最多 100 万次，二分最多 </font>**<font style="color:rgb(15, 17, 21);">20 次</font>**<font style="color:rgb(15, 17, 21);">。</font>

---

## <font style="color:rgb(15, 17, 21);">前提条件</font>
<font style="color:rgb(15, 17, 21);">二分查找不是随便用的，必须满足：</font>

1. **<font style="color:rgb(15, 17, 21);">数据有序</font>**<font style="color:rgb(15, 17, 21);">（升序或降序）</font>
2. **<font style="color:rgb(15, 17, 21);">支持随机访问</font>**<font style="color:rgb(15, 17, 21);">（数组可以，链表不行）</font>

<font style="color:rgb(15, 17, 21);">如果数组无序，要么先排序（O(n log n)），要么换哈希表。</font>

## <font style="color:rgb(15, 17, 21);">最基础模板：查找目标值</font>
<font style="color:rgb(15, 17, 21);">在升序数组 nums 中查找 target，找到返回索引，找不到返回 -1。</font>

```plain
def binarySearch(nums, target):
    left, right = 0, len(nums) - 1        # 闭区间 [left, right]
    while left <= right:
        mid = left + (right - left) // 2  # 防止溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1                # 目标在右半区
        else:
            right = mid - 1               # 目标在左半区
    return -1

#防止溢出
int 最大21亿时
int left = 2000000000;
int right = 2000000000;
int mid = (left+right) /2 //溢出！ error
```

### 示例
```plain
nums = [1, 3, 5, 7, 9, 11, 13]   target = 7

left=0  right=6  mid=3  nums[3]=7  → 找到！返回 3
```

```plain
nums = [1, 3, 5, 7, 9, 11, 13]   target = 8

left=0  right=6  mid=3  nums[3]=7 < 8  → left=4
left=4  right=6  mid=5  nums[5]=11 > 8 → right=4
left=4  right=4  mid=4  nums[4]=9 > 8  → right=3
left=4  right=3  循环结束  → 返回 -1
```

### <font style="color:rgb(15, 17, 21);">图解</font>
```plain
[1, 3, 5, 7, 9, 11, 13]
 L        M           R      nums[M]=7 < 8，排除左半
          L  M        R      nums[M]=11 > 8，排除右半
          L  M  R            nums[M]=9 > 8，排除右半
             R  L            区间为空，找不到
```

## <font style="color:rgb(15, 17, 21);">关键细节：mid 的写法</font>
```plain
mid = left + (right - left) // 2
```

**<font style="color:rgb(15, 17, 21);">为什么不写 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">(left + right) // 2</font>**`**<font style="color:rgb(15, 17, 21);">？</font>**

<font style="color:rgb(15, 17, 21);">因为 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left + right</font>`<font style="color:rgb(15, 17, 21);"> 可能</font>**<font style="color:rgb(15, 17, 21);">溢出</font>**<font style="color:rgb(15, 17, 21);">（尤其在 C/C++/Java 中）。Python 整数不会溢出，但</font>**<font style="color:rgb(15, 17, 21);">养成这个习惯</font>**<font style="color:rgb(15, 17, 21);">是好的。</font>

<font style="color:rgb(15, 17, 21);">两种等价写法：</font>

```plain
mid = left + (right - left) // 2   # 推荐
mid = (left + right) // 2          # 简单，但可能溢出
```

---

## <font style="color:rgb(15, 17, 21);">区间的两种写法</font>
<font style="color:rgb(15, 17, 21);">二分查找最容易搞混的就是</font>**<font style="color:rgb(15, 17, 21);">区间定义</font>**<font style="color:rgb(15, 17, 21);">。有两种流派：</font>

| <font style="color:rgb(15, 17, 21);">流派</font> | <font style="color:rgb(15, 17, 21);">区间</font> | <font style="color:rgb(15, 17, 21);">初始 right</font> | <font style="color:rgb(15, 17, 21);">循环条件</font> | <font style="color:rgb(15, 17, 21);">移动方式</font> |
| --- | --- | --- | --- | --- |
| **<font style="color:rgb(15, 17, 21);">闭区间</font>** | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">[left, right]</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">len(nums)-1</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left <= right</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left=mid+1, right=mid-1</font>` |
| **<font style="color:rgb(15, 17, 21);">左闭右开</font>** | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">[left, right)</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">len(nums)</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left < right</font>` | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left=mid+1, right=mid</font>` |


**<font style="color:rgb(15, 17, 21);">建议：只掌握一种，别混用。</font>**<font style="color:rgb(15, 17, 21);"> 下面用</font>**<font style="color:rgb(15, 17, 21);">闭区间</font>**<font style="color:rgb(15, 17, 21);">为主。</font>

## <font style="color:rgb(15, 17, 21);">进阶：查找左右边界</font>
<font style="color:rgb(15, 17, 21);">基础模板只能找"某一个"目标，但如果有重复元素，想找</font>**<font style="color:rgb(15, 17, 21);">第一个</font>**<font style="color:rgb(15, 17, 21);">或</font>**<font style="color:rgb(15, 17, 21);">最后一个</font>**<font style="color:rgb(15, 17, 21);">，就要变形。</font>

### <font style="color:rgb(15, 17, 21);">例题：查找第一个等于 target 的位置</font>
<font style="color:rgb(15, 17, 21);">nums = [1, 2, 2, 2, 3, 4]，target = 2，返回索引 1（第一个 2）。</font>

```plain
def lowerBound(nums, target):
    left, right = 0, len(nums) - 1
    ans = -1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            ans = mid
            right = mid - 1        # 找到后不返回，继续往左找
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return ans
```

**<font style="color:rgb(15, 17, 21);">关键：找到 target 后不返回，而是继续收缩右边界，找更左的。</font>**

### <font style="color:rgb(15, 17, 21);">例题：查找最后一个等于 target 的位置</font>
```plain
def upperBound(nums, target):
    left, right = 0, len(nums) - 1
    ans = -1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            ans = mid
            left = mid + 1         # 找到后继续往右找
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return ans
```

### <font style="color:rgb(15, 17, 21);">对比</font>
| <font style="color:rgb(15, 17, 21);">目标</font> | <font style="color:rgb(15, 17, 21);">找到后动作</font> |
| --- | --- |
| <font style="color:rgb(15, 17, 21);">任意一个</font> | <font style="color:rgb(15, 17, 21);">直接 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">return mid</font>` |
| <font style="color:rgb(15, 17, 21);">第一个</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">right = mid - 1</font>`<br/><font style="color:rgb(15, 17, 21);">，继续找</font> |
| <font style="color:rgb(15, 17, 21);">最后一个</font> | `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left = mid + 1</font>`<br/><font style="color:rgb(15, 17, 21);">，继续找</font> |


## <font style="color:rgb(15, 17, 21);">进阶：查找插入位置</font>
<font style="color:rgb(15, 17, 21);">在有序数组中找 target，找到返回索引，找不到返回它应该插入的位置。</font>

```plain
def searchInsert(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return left        # 循环结束时 left 就是插入位置
```

**<font style="color:rgb(15, 17, 21);">注意：循环结束后 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">left</font>**`**<font style="color:rgb(15, 17, 21);"> 正好是插入位置。</font>**

## <font style="color:rgb(15, 17, 21);">进阶：二分答案</font>
<font style="color:rgb(15, 17, 21);">有些题</font>**<font style="color:rgb(15, 17, 21);">不是查找数组元素</font>**<font style="color:rgb(15, 17, 21);">，而是</font>**<font style="color:rgb(15, 17, 21);">对答案进行二分</font>**<font style="color:rgb(15, 17, 21);">。</font>

### <font style="color:rgb(15, 17, 21);">例题：求平方根</font>
<font style="color:rgb(15, 17, 21);">求 x 的平方根，向下取整。</font>

```plain
def mySqrt(x):
    left, right = 0, x
    ans = 0
    while left <= right:
        mid = left + (right - left) // 2
        if mid * mid <= x:
            ans = mid              # 记录可行答案
            left = mid + 1         # 试着找更大的
        else:
            right = mid - 1
    return ans
```

**<font style="color:rgb(15, 17, 21);">思路：答案在 [0, x] 之间，二分猜测。</font>**

### <font style="color:rgb(15, 17, 21);">例题：爱吃香蕉的珂珂</font>
<font style="color:rgb(15, 17, 21);">珂珂每小时吃 k 根香蕉，要在 h 小时内吃完所有香蕉，求最小 k。</font>

```plain
def minEatingSpeed(piles, h):
    def canFinish(k):
        hours = sum((p + k - 1) // k for p in piles)   # 向上取整
        return hours <= h
    
    left, right = 1, max(piles)
    while left < right:
        mid = left + (right - left) // 2
        if canFinish(mid):
            right = mid           # mid 可行，试着更小
        else:
            left = mid + 1        # mid 不可行，必须更大
    return left
```

**<font style="color:rgb(15, 17, 21);">二分答案的关键：找到"单调性"，把问题变成"判断某个值行不行"。</font>**

## <font style="color:rgb(15, 17, 21);">二分的识别信号</font>
<font style="color:rgb(15, 17, 21);">看到以下关键词，考虑二分：</font>

+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">有序数组</font>**<font style="color:rgb(15, 17, 21);">查找</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">O(log n)</font>**<font style="color:rgb(15, 17, 21);"> 要求</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">找边界</font>**<font style="color:rgb(15, 17, 21);">（第一个/最后一个）</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">插入位置</font>**
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">求最小/最大的可行值</font>**<font style="color:rgb(15, 17, 21);">（二分答案）</font>
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">旋转有序数组</font>**
+ <font style="color:rgb(15, 17, 21);">✅</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">单调性</font>**

left, right = 0, len(nums) - 1

while left <= right:
    mid = left + (right - left) // 2
    if nums[mid] == target:

        right = mid - 1
    elif nums[mid] < target:

    else:

return ans

### <font style="color:rgb(15, 17, 21);">模板三：二分答案</font>
