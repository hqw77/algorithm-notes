# 二分查找
## 什么是二分查找
二分查找(Binary Search)是一种在**有序数据**中快速查找目标的算法:

每次取中间元素和目标比较,**排除一半**不可能的范围,不断缩小查找区间,直到找到目标或区间为空.

核心价值:把 **O(n)** 的线性查找优化到 **O(log n)**.

比如 100 万个数据,线性查找最多 100 万次,二分最多 **20 次**.

---

## 前提条件
二分查找不是随便用的,必须满足:

1. **数据有序**(升序或降序)
2. **支持随机访问**(数组可以,链表不行)

如果数组无序,要么先排序(O(n log n)),要么换哈希表.

## 最基础模板:查找目标值
在升序数组 nums 中查找 target,找到返回索引,找不到返回 -1.

```plain
def binarySearch(nums, target):
    left, right = 0, len(nums) - 1        # 闭区间 [left, right]
    while left <= right:
        mid = left + (right - left) // 2  # 防止溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1                # 目标在右半区
        else:
            right = mid - 1               # 目标在左半区
    return -1

#防止溢出
int 最大21亿时
int left = 2000000000;
int right = 2000000000;
int mid = (left+right) /2 //溢出! error
```

### 示例
```plain
nums = [1, 3, 5, 7, 9, 11, 13]   target = 7

left=0  right=6  mid=3  nums[3]=7  -> 找到!返回 3
```

```plain
nums = [1, 3, 5, 7, 9, 11, 13]   target = 8

left=0  right=6  mid=3  nums[3]=7 < 8  -> left=4
left=4  right=6  mid=5  nums[5]=11 > 8 -> right=4
left=4  right=4  mid=4  nums[4]=9 > 8  -> right=3
left=4  right=3  循环结束  -> 返回 -1
```


## 关键细节:mid 的写法
```plain
mid = left + (right - left) // 2
```

**为什么不写 **`**(left + right) // 2**`**?**

因为 `left + right` 可能**溢出**(尤其在 C/C++/Java 中).Python 整数不会溢出,但**养成这个习惯**是好的.

两种等价写法:

```plain
mid = left + (right - left) // 2   # 推荐
mid = (left + right) // 2          # 简单,但可能溢出
```

---

## 区间的两种写法
二分查找最容易搞混的就是**区间定义**.有两种流派:

| 流派 | 区间 | 初始 right | 循环条件 | 移动方式 |
| --- | --- | --- | --- | --- |
| **闭区间** | `[left, right]` | `len(nums)-1` | `left <= right` | `left=mid+1, right=mid-1` |
| **左闭右开** | `[left, right)` | `len(nums)` | `left < right` | `left=mid+1, right=mid` |


**建议:只掌握一种,别混用.** 下面用**闭区间**为主.

## 进阶:查找左右边界
基础模板只能找"某一个"目标,但如果有重复元素,想找**第一个**或**最后一个**,就要变形.

### 例题:查找第一个等于 target 的位置
nums = [1, 2, 2, 2, 3, 4],target = 2,返回索引 1(第一个 2).

```plain
def lowerBound(nums, target):
    left, right = 0, len(nums) - 1
    ans = -1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            ans = mid
            right = mid - 1        # 找到后不返回,继续往左找
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return ans
```

**关键:找到 target 后不返回,而是继续收缩右边界,找更左的.**

### 例题:查找最后一个等于 target 的位置
```plain
def upperBound(nums, target):
    left, right = 0, len(nums) - 1
    ans = -1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            ans = mid
            left = mid + 1         # 找到后继续往右找
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return ans
```

### 对比
| 目标 | 找到后动作 |
| --- | --- |
| 任意一个 | 直接 `return mid` |
| 第一个 | `right = mid - 1`,继续找 |
| 最后一个 | `left = mid + 1`,继续找 |


## 进阶:查找插入位置
在有序数组中找 target,找到返回索引,找不到返回它应该插入的位置.

```plain
def searchInsert(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return left        # 循环结束时 left 就是插入位置
```

**注意:循环结束后 **`**left**`** 正好是插入位置.**

## 进阶:二分答案
有些题**不是查找数组元素**,而是**对答案进行二分**.

### 例题:求平方根
求 x 的平方根,向下取整.

```plain
def mySqrt(x):
    left, right = 0, x
    ans = 0
    while left <= right:
        mid = left + (right - left) // 2
        if mid * mid <= x:
            ans = mid              # 记录可行答案
            left = mid + 1         # 试着找更大的
        else:
            right = mid - 1
    return ans
```

**思路:答案在 [0, x] 之间,二分猜测.**

### 例题:爱吃香蕉的珂珂
珂珂每小时吃 k 根香蕉,要在 h 小时内吃完所有香蕉,求最小 k.

```plain
def minEatingSpeed(piles, h):
    def canFinish(k):
        hours = sum((p + k - 1) // k for p in piles)   # 向上取整
        return hours <= h
    
    left, right = 1, max(piles)
    while left < right:
        mid = left + (right - left) // 2
        if canFinish(mid):
            right = mid           # mid 可行,试着更小
        else:
            left = mid + 1        # mid 不可行,必须更大
    return left
```

**二分答案的关键:找到"单调性",把问题变成"判断某个值行不行".**

## 二分的识别信号
看到以下关键词,考虑二分:

+ ✅ **有序数组**查找
+ ✅ **O(log n)** 要求
+ ✅ **找边界**(第一个/最后一个)
+ ✅ **插入位置**
+ ✅ **求最小/最大的可行值**(二分答案)
+ ✅ **旋转有序数组**
+ ✅ **单调性**

```plain
left, right = 0, len(nums) - 1
ans = -1
while left <= right:

        right = mid - 1
    elif nums[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
return ans
```
